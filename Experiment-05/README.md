# Experiment 05: SHA-256 Hash Generation and Digital Signature Verification Using OpenSSL

## Objective
To generate SHA-256 hash values, create digital signatures, and verify their authenticity using OpenSSL.

## Software Required
1. OpenSSL
2. Windows Command Prompt (CMD)

## Algorithms Used
1. SHA-256
2. RSA Digital Signature

## Procedure
1. Open Command Prompt and navigate to the practical folder.
2. Check the installed OpenSSL version.
3. Generate the SHA-256 hash value of message.txt.
4. Create a digital signature using the RSA private key.
5. Verify the digital signature using the corresponding public key.
6. Check the verification result. "Verified OK" indicates successful verification.
7. View the generated files using the dir command.
