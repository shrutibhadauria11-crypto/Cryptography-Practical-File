# Experiment 02: Frequency Analysis

## Objective
To study frequency analysis and understand how letter frequency can be used to analyze and break classical substitution ciphers.

## Software Used
CrypTool 2

## Procedure
1. Opened the ciphertext in CrypTool 2.
2. Performed frequency analysis.
3. Observed the frequency distribution of letters.
4. Analyzed the results to understand possible plaintext patterns.
