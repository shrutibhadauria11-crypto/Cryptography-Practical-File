# Experiment 03: Encryption Using DES and AES Algorithms

## Objective
To encrypt sample data using DES and AES algorithms and compare their security features and performance.

## Software Used
CrypTool 2.1

## Sample Plaintext
HELLO BTECH STUDENTS

## Algorithms Used
1. DES (Data Encryption Standard)
2. AES (Advanced Encryption Standard)

## Procedure
1. Open CrypTool 2.1.
2. Enter the sample plaintext.
3. Perform encryption using DES with a valid key.
4. Decrypt the ciphertext using the same key.
5. Perform encryption using AES with a valid key.
6. Decrypt the AES ciphertext using the same key.
7. Verify that the original plaintext is recovered.

## Comparison of DES and AES

| Feature | DES | AES |
|---|---|---|
| Key Size | 56-bit effective | 128, 192, 256 bits |
| Block Size | 64 bits | 128 bits |
| Security | Weak | Strong |
| Performance | Good on older systems | Efficient on modern systems |
| Usage | Outdated | Widely used |
