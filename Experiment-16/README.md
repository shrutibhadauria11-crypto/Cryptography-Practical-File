# Experiment-16: Secure Wireless Network Using WPA2

## Objective
To design and implement a secure wireless network using WPA2 encryption (AES) in Cisco Packet Tracer and verify secure communication.

## Tools Required
- Cisco Packet Tracer
- Wireless Router
- Laptops or PCs
- Ethernet cables (if required)

## Theory
A wireless network allows devices to communicate without physical cables.

WPA2 (Wi-Fi Protected Access 2) is a wireless security protocol that protects Wi-Fi networks. It uses AES (Advanced Encryption Standard) to encrypt data and prevent unauthorized access.

In this experiment, a wireless router is configured with WPA2-PSK security and AES encryption. A strong password is used to allow only authorized devices to connect.

## Procedure
1. Open Cisco Packet Tracer.
2. Add a wireless router and laptops or PCs to the workspace.
3. Configure the wireless router.
4. Set the SSID (network name).
5. Select WPA2-PSK security.
6. Select AES encryption.
7. Set a strong wireless password.
8. Connect the wireless devices using the correct password.
9. Configure or obtain IP addresses using DHCP.
10. Verify communication using the ping command.

## Output
- Wireless Router Setup and DHCP Configuration
- Cisco Packet Tracer Network Topology
- Laptop DHCP IP Configuration Success
- Command Prompt Ping Test Verification

## Result
A secure wireless network was successfully designed using WPA2-PSK with AES encryption in Cisco Packet Tracer. Communication between connected devices was verified using the ping command.
