# Experiment 01: Classical Encryption Techniques

## Objective
To implement Caesar, Vigenère, and Rail Fence ciphers to encrypt and decrypt plaintext, and compare their working and effectiveness.

## Software Used
CrypTool 2

## Techniques Performed
1. Caesar Cipher
2. Vigenère Cipher
3. Rail Fence Cipher
